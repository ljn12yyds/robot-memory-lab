# 人工介入数据：研究依据与本项目方案

## 1. 别人通常如何使用人工介入

人工介入不是普通的完整示范。它的价值在于：策略先把机器人带到了自己容易
失败的状态，人类只在困难位置接管并给出纠正动作。

- DAgger 反复执行当前策略，在策略实际访问的状态上收集专家动作，再聚合数据
  训练，解决纯 BC 的状态分布偏移。
- HG-DAgger 让人只在认为危险或错误时接管，避免专家在没有控制权时隔空标注。
- IWR 把介入样本和非介入样本分开，并在训练 batch 中等比例采样；这会显著
  提高稀少纠正样本的影响，同时用非介入数据约束策略不要整体漂移。
- Sirius 把人的介入看作“对策略不信任”的隐式信号，用信任估计做加权 BC。
- EIL 同时利用“没有介入”和“发生介入”的隐式信息，将轨迹分为可接受段、
  接管前不良段和人类动作段，并通过价值约束学习。
- HIL-SERL 走得更远：示范和介入进入 replay buffer，通过离策略 RL、奖励
  分类器和价值函数学习，而不是直接给每一段固定 advantage。

主要资料：

- DAgger: https://proceedings.mlr.press/v15/ross11a.html
- HG-DAgger: https://arxiv.org/abs/1810.02890
- IWR: https://sites.google.com/stanford.edu/iwr
- Sirius: https://arxiv.org/abs/2211.08416
- EIL: https://roboticsconference.org/2020/program/papers/55.html
- ReIL: https://arxiv.org/abs/2203.15390
- ThriftyDAgger: https://arxiv.org/abs/2109.08273

## 2. 能否按片段赋权

可以。IWR 和 Sirius 都支持“介入数据应该比普通数据得到更多训练关注”。
不过，当前项目的固定 `advantage=-0.5/+1.0` 更准确的名称是：

> 人工介入感知的分段加权行为克隆

它还不是严格意义上由回报、Q 函数或价值函数估计出来的 AWR advantage。
`exp(advantage)` 只是把人工设定的分数转换成正的 loss 权重。

## 3. 为什么当前阶段不采用 IWR 1:1

IWR 的 1:1 指训练 batch 中“介入样本/非介入样本”的采样比例，不是要求
策略 rollout 天然达到 50% 成功率。但本项目当前策略成功率很低，非介入
数据里会包含大量失败动作。将这些动作与人工动作等量模仿，会继续强化弱
策略。因此当前阶段更适合：

1. 保留原始 BC 示范作为稳定锚点；
2. 使用 HG-DAgger 式人工接管产生当前策略状态上的纠正；
3. 使用 EIL/Sirius 式片段可信度区分，而不是简单 1:1；
4. 等策略成功率明显提高后，再测试 IWR balanced sampling。

ReIL 也报告纯监督式 HG-DAgger/IWR 可能出现性能退化，并采用 RL 与 imitation
结合来处理稀疏纠正；这支持我们不要在低成功率阶段直接照搬 IWR。

## 4. 当前粗分段方案的风险

将“接管前全部动作”设为负权重并不严谨：

- 前半段接近物体、移动到抓取区域的动作可能完全正确；
- 真正导致接管的通常只是接管前短时间内的偏差；
- 对整段降权可能破坏已经学会的正确到达动作；
- 失败动作即使 advantage 为负，经过指数后权重仍大于零，因此训练仍会在
  较弱程度上模仿它，不能等同于“反向学习”。

## 5. 推荐的三段式训练

第一轮建议将成功介入 Episode 分成三段：

| 片段 | 建议处理 |
| --- | --- |
| 早期自主执行且没有明显错误 | 保持中性或沿用 Episode 权重 |
| 接管前 0.5–2 秒风险窗口 | 降权或从 actor loss 排除 |
| 接管后的人工纠正 | 提高采样率或提高 loss 权重 |

无人工介入且成功的 Episode 应保留为高质量自主样本。失败 Episode 对未来训练
奖励模型或 Q 函数很有价值，但在只有加权 BC 的第一版中，不应把它当作专家
动作强力模仿。

代码当前默认风险窗口为接管前 90 帧，在 30 fps 下约为 3 秒。可通过
`BARBELL_INTERVENTION_RISK_WINDOW_FRAMES` 调整。

## 6. 本任务的推荐实验顺序

为判断提升来自哪里，每轮只改变一个因素，并用相同初始场景测试：

1. 基线：原 BC checkpoint；
2. 三段式：BC 数据作锚点，接管前 90 帧降权，成功人工纠正段升权；
3. 比较风险窗口 30、60、90 帧；
4. 策略成功率提高后，再把 IWR balanced sampling 作为消融对照；
5. 数据量足够后，引入奖励分类器和离策略 critic，升级为真正的 HIL RL。

每个模型至少记录：总成功率、无需介入成功率、介入率、抓取阶段失败率、
平均完成时间和各初始物体位置的成功率。只有“无需介入成功率”上升，才说明
策略本身真正学会了纠正行为。
