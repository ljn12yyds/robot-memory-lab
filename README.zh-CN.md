# Robot Memory Lab

本仓库整理了 SO-101 真机操作、SmolVLA 和 pi0.5 微调、Evo-RL 人工介入采集，以及长程任务上层记忆的研究代码。这里保存的是我们自己的脚本与针对固定上游版本的补丁，不包含完整上游源码、机器人数据、标定文件或模型权重。[English README](README.md) 和 [上游版本说明](UPSTREAMS.md) 提供复现入口。

## 目前做到了什么

- `so101_barbell/`：杠铃任务的数据采集、SmolVLA/pi0.5 训练与安全推理、HIL 采集和数据整理。pi0.5 曾在真机上完成一次现场确认的抓取放置，但没有足够的多轮成功率数据，不能据此声称策略稳定。
- `patches/` 与 `overlays/evo_rl/`：LeRobot、Evo-RL 和 RoboTwin 的本地改动。补丁必须应用到 [UPSTREAMS.md](UPSTREAMS.md) 中指定的提交。
- `task_memory_agent/` 与 `libero_eval/`：上层任务规划、JSON 记忆、子任务接口，以及使用 Qwen3-VL 和官方 pi0.5-LIBERO 的仿真评测脚本。

## 第一项受控记忆实验

[2026-10-19 LIBERO 一次性视觉提示实验](experiments/transient_cue_20261019/README.md)使用 5 个初始状态，每个状态分别给出红色或绿色提示。机械臂先执行相同的番茄酱放置任务；提示消失后，红色要求停止，绿色要求继续放置烧烤酱。同一初始状态的两条试验在决策时具有字节一致的当前图像。

| 决策条件 | 正确完成任务目标 |
| --- | ---: |
| 保留早期提示的任务记忆 | 10/10 |
| 删除该记忆字段 | 5/10 |

第一阶段放置与松手检查、提示识别均通过；绿色分支的下层继续执行也成功。这个结果说明，在**人工构造的一次性提示任务**中，上层持久化记忆能够改变正确的子任务选择。红绿规则直接写在 VLM 提示词里，样本只有 5 组，也没有测试自然场景、未见任务、长期真实机器人运行或新训练出的记忆机制。详细协议和逐次汇总见实验目录。原始 JSON、仿真图像和视频不公开。

## 使用边界

仓库不是开箱即用的机器人控制软件。运行前需分别安装固定版本的上游项目，取得所需模型与数据，并按本机设备修改路径、相机、机械臂 ID、标定和安全限位。公开版本中的硬件序列号均已换成占位符。真机动作必须先完成只读与短时安全检查；不要根据仿真结果直接授权长时间运行。
